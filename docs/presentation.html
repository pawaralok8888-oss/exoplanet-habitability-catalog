DATABASE SCHEMA & 3NF

Relational Modeling & Foreign Key Integrity

⭐ PARENT: stars (3,010 Records)
CREATE TABLE stars (
  star_id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL UNIQUE,
  spectral_type VARCHAR(30),
  temperature DECIMAL(10,2),
  radius DECIMAL(10,4),
  mass DECIMAL(10,4),
  luminosity DECIMAL(14,6),
  distance_from_earth DECIMAL(12,4)
);
🪐 CHILD: exoplanets (4,048 Records)
CREATE TABLE exoplanets (
  planet_id INT AUTO_INCREMENT PRIMARY KEY,
  star_id INT NOT NULL, -- FOREIGN KEY
  name VARCHAR(100) NOT NULL UNIQUE,
  radius DECIMAL(10,4),
  mass DECIMAL(10,4),
  predicted_habitability DECIMAL(5,4),
  telemetry_json JSON, -- NoSQL Doc
  CONSTRAINT fk_planet_star FOREIGN KEY (star_id)
    REFERENCES stars(star_id) ON DELETE CASCADE
);
🔒 ON DELETE CASCADE prevents orphan planetary records when stars are decommissioned.

THE INNOVATION ENGINE

Confidence Drift Trigger (AFTER UPDATE)

⚡ trg_after_exoplanet_update
CREATE TRIGGER trg_after_exoplanet_update AFTER UPDATE ON exoplanets
FOR EACH ROW BEGIN
  DECLARE delta DECIMAL(6,4);
  IF (NEW.predicted_habitability <> OLD.predicted_habitability) THEN
    SET delta = NEW.predicted_habitability - OLD.predicted_habitability;
    IF ABS(delta) >= 0.15 THEN -- 15% Scientific Shift Threshold
      SET is_drift_alert = 1;
      SET note_text = CONCAT('CONFIDENCE DRIFT: Delta ', ROUND(delta*100,1), '%');
    END IF;
    INSERT INTO habitability_log (planet_id, old_score, new_score, delta, is_drift_alert, notes)
    VALUES (NEW.planet_id, OLD.predicted_habitability, NEW.predicted_habitability, delta, is_drift_alert, note_text);
  END IF;
END;
🎯 Key DBMS Principles
  • Pseudorecords: Uses OLD and NEW to track score before and after transaction.
  • Autonomous Logic: Database autonomously calculates variance and triggers alerts.
  • Audit Integrity: Writes immutable history to habitability_log table.

MACHINE LEARNING

Random Forest Classifier (200 Estimators)

🌳 The Model Architecture
  • Ensemble of 200 de-correlated decision trees.
  • Non-linear boundary handling: Planets too hot or too cold are uninhabitable.
  • Extreme Class Imbalance: Only ~1.4% (57/4048) of planets are habitable.
  • Handled via class_weight='balanced' to heavily penalize false negatives.
🧬 10-Dimensional Feature Vector
